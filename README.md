# Escala dos Coroinhas — Paróquia São Benedito Bauru

Aplicativo web responsivo, sem dependências externas, para uso no navegador do celular ou computador.

## Como publicar

1. Publique este repositório em qualquer hospedagem de site estático, como GitHub Pages, Netlify ou Vercel.
2. Abra o endereço publicado no navegador.
3. Os dados ficam salvos no navegador por meio de `localStorage`. Para uso compartilhado entre vários dispositivos, será necessário conectar um banco de dados em uma próxima etapa.

## Recursos incluídos

- Cadastro dos 30 coroinhas e 40 acólitos fornecidos.
- Ciclo inicial de novembro de 2026 a outubro de 2027.
- Celebrações apenas aos sábados e domingos:
  - Matriz São Benedito: sábado 17h; domingo 10h e 19h.
  - Capela Nossa Senhora da Penha: sábado 19h.
  - Capela Nossa Senhora de Lourdes: domingo 8h.
- Quantidades de coroinhas e acólitos editáveis por celebração.
- Disponibilidade por celebração.
- Geração de escala preliminar com distribuição equilibrada e alertas de vagas.
- Revisão manual dos nomes escalados.
- Impressão e salvamento como PDF pelo navegador.

## Observação sobre o arquivo original

Os participantes e as observações textuais da planilha foram cadastrados. A classificação foi baseada nas seções `COROINHAS` e `ACOLITOS` exibidas no arquivo fornecido. O registro histórico de `OK` não foi convertido automaticamente em indisponibilidade, pois ele significa que a pessoa já foi escalada naquela data e deve ser considerado durante a revisão.
